SafeLink

Main Idea

Our idea is to make a website that checks if a URL is safe or not.

Goal

Help people check links before they open them.

How It Works

The user can enter a URL, a message that has a URL in it, or they can scan a QR code. The website will check the link and then give the user a rating out of 10. The rating will help the user know how safe or unsafe the link is.

Design

The website will have a simple and easy-to-use design so people of all ages, including older users, can easily use it and understand the results.
